\# E-Commerce Website



A basic e-commerce website developed using \*\*HTML, CSS, JavaScript, Python, and Django\*\*.



\## Features



\* User Registration and Login

\* Product Listing

\* Product Details

\* Shopping Cart

\* Add and Remove Products from Cart

\* Order Processing

\* Payment Method Selection

\* Product Images

\* SQLite Database

\* Django Admin Panel



\## Technologies Used



\* HTML

\* CSS

\* JavaScript

\* Python

\* Django

\* SQLite



\## Project Structure



\* `ecommerce/` – Main Django project

\* `store/` – E-commerce application

\* `templates/` – HTML templates

\* `media/` – Product images

\* `db.sqlite3` – Database

\* `manage.py` – Django management file



\## How to Run



1\. Clone the repository.

2\. Open the project folder in a terminal.

3\. Run:



```bash

python manage.py runserver

```



4\. Open the local server in your browser.
